# Прокат лыж — сайт бронирования времени проката

Веб-приложение на **FastAPI + SQLite + Jinja2**: регистрация, бронирование лыжного инвентаря,
личный кабинет пользователя с изменением времени проката, интерфейсы сотрудника и администратора,
REST API для работы интерфейсов.

## Запуск

```bash
pip install -r requirements.txt
python run.py            # http://127.0.0.1:8000
```

Документация API (Swagger): `http://127.0.0.1:8000/docs`

Демо-аккаунты (создаются автоматически): `admin / admin123`, `employee / emp123`.

## Структура

```
app/
  main.py        — веб-интерфейсы (главная, регистрация, вход, кабинет, панели)
  api.py         — REST API администратора и сотрудника
  auth.py        — хеширование паролей, сессии (cookie), проверка ролей
  database.py    — SQLite: users, equipment, bookings + инициализация
  templates/     — base, index, register, login, cabinet, book, edit_booking, employee, admin
  static/css/    — стили
run.py           — точка входа (uvicorn)
```

## Возможности

### Пользователь
- Регистрация (`/register`) и вход (`/login`), роли: user / employee / admin.
- Просмотр доступного инвентаря на главной (`/`).
- Бронирование: выбор инвентаря, даты, времени начала, длительности (`/cabinet/book`).
  Защита от пересечений (один инвентарь — одна бронь на дату/время).
- Личный кабинет (`/cabinet`): список броней, **изменение времени проката**, отмена брони.

### Сотрудник (`/employee`)
- Список бронирований по дате (клиенты, телефоны, инвентарь, статус).
- Корректировка любой брони (дата/время/длительность/инвентарь) через модальное окно + API.
- Отметка «завершена». Поиск свободного инвентаря на выбранное время.

### Администратор (`/admin`)
- Статистика (пользователи, брони, активные, инвентарь).
- CRUD пользователей: создание, редактирование ФИО/телефона/роли/пароля, удаление.
- CRUD инвентаря: название, тип, размер, статус (ok / обслуживание); запрет удаления занятого.

## API (требует cookie-сессии после `/login`)

Admin API (`/api/admin`):
- `GET/POST /users`, `PUT/DELETE /users/{id}`
- `GET/POST /equipment`, `PUT/DELETE /equipment/{id}`
- `GET /stats`

Employee API (`/api/employee`):
- `GET /bookings?date=YYYY-MM-DD&status=active`
- `PUT /bookings/{id}` — изменить время/длительность/инвентарь/статус
- `POST /bookings/{id}/complete` — завершить прокат
- `GET /free-equipment?date=...&start_time=HH:MM` — свободный инвентарь

Неавторизованный запрос → `401`, запрос не своей ролью → `403`, конфликт брони → `409`.
